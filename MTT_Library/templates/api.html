Library API

Django + MongoDB + Redis cache + PyJWT.

Các endpoint cần xác thực sử dụng header Authorization: Bearer <access_token>. Đăng nhập bằng tài khoản admin để thao tác quản trị.

Authentication

MethodURLQuyềnThao tác
POST/register/PublicĐăng ký tài khoản user.
POST/login/PublicĐăng nhập, nhận access token và refresh token.
POST/refresh/PublicĐổi refresh token cũ lấy cặp token mới.
POST/logout/JWTThu hồi access token và refresh token.

Books CRUD

MethodURLQuyềnThao tác
GET/books/PublicXem danh sách books, có cache.
POST/books/create/JWTTạo book mới, owner lấy từ token.
GET/books/<id>/PublicXem chi tiết book.
PUT/books/<id>/Owner/AdminCập nhật book.
DELETE/books/<id>/Owner/AdminXóa book.

Admin Operations

MethodURLThao tác
GET/admin/users/Xem danh sách users, không hiển thị password hash.
POST/admin/users/create/Tạo user với role user hoặc admin.
PUT/admin/users/<username>/Cập nhật role hoặc password.
DELETE/admin/users/<username>/Xóa user khác, admin không thể tự xóa mình.

Admin Flow

  1. Gọi POST /login/ với tài khoản admin.
  2. Lấy giá trị access_token trong response.
  3. Gửi token qua header Authorization: Bearer <access_token>.
  4. Gọi các endpoint trong nhóm /admin/users/.
